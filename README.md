# KajKhoj — Job Portal for Local & Agricultural Workers

KajKhoj ("work search") connects local skilled workers (farmhands, plumbers, electricians, carpenters, daily-wage workers) with employers.

**Stack:** Next.js · Tailwind CSS · Redux Toolkit · MongoDB · JWT

## Features
**Workers:** profile, job search, apply and track applications, bookmark jobs, upload CV/certificates.
**Employers:** post jobs, manage posted jobs, review applications, accept/reject with status updates.
**Platform:** JWT auth, dashboard data tables, organizations directory.

## Run locally
```bash
npm install
cp .env.example .env   # then fill in your values
npm run dev
```
